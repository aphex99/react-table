# Products Table

SPA-приложение для управления каталогом товаров с серверной пагинацией, сортировкой, поиском и формами

**[Live Demo](https://aphex99.github.io/react-table/)**

## Технологии

- **React 19, TypeScript** — пользовательский интерфейс и типизация
- **TanStack Query** — управление серверным состоянием и кэширование запросов
- **React Router** — маршрутизация
- **React Hook Form, Zod** — управление формами и валидация данных
- **Axios** — взаимодействие с REST API
- **SCSS, CSS Modules** — стилизация компонентов
- **Vite** — сборка приложения

## Функциональность

### Таблица товаров

- Получение данных через API
- Серверная пагинация и сортировка
- Поиск товаров
- Циклическая сортировка: без сортировки → ASC → DESC → без сортировки

### Управление состоянием запросов

- Кэширование серверных данных с TanStack Query
- Сохранение предыдущих данных при переключении страниц (`keepPreviousData`)
- Skeleton при первоначальной загрузке
- Progress bar при фоновых запросах

### Формы

- Управление состоянием форм через React Hook Form
- Валидация данных с использованием Zod

## Архитектура

Проект организован по feature-based подходу с разделением ответственности между слоями:

- `app` — инициализация приложения и маршрутизация
- `pages` — страницы приложения
- `features` — пользовательские сценарии (поиск, добавление товара)
- `entities` — бизнес-сущности и связанные компоненты
- `shared` — переиспользуемые UI-компоненты, API-клиент, конфигурация и ресурсы

## Локальный запуск

**Установка зависимостей**

```bash
pnpm install
```

**Запуск приложения**

```bash
pnpm start
```

**Проверка кода и типов**

```bash
pnpm lint
pnpm types
```

**Production-сборка**

```bash
pnpm build
```
